# Madeline Jewett — Portfolio Website

Personal portfolio for **Madeline “Maddie” Jewett**, focused on computer science, data science, machine learning, healthcare AI, medical imaging, and behavioral research.

**Live site:** https://jewettm530.github.io

## Featured case studies

- Mental Health Symptom Severity — behavioral + resting-state fMRI machine learning
- EchoNet-Dynamic Research — echocardiography, segmentation, and EF modeling
- Puberty & Virtual Reality — reward learning, stress, heart rate, EEG, and multimodal analysis
- Portfolio Research Assistant — explainable decision-support software in Python/Streamlit

## Stack

The site intentionally uses a lightweight static stack:

- HTML
- CSS
- vanilla JavaScript
- GitHub Pages

No build step or framework is required.

## Publishing

For a repository named `jewettm530.github.io`, GitHub Pages can publish directly from the repository's default branch. In **Settings → Pages**, choose **Deploy from a branch**, then select the root of `main` if Pages is not already enabled.
