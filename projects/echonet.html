EchoNet-Dynamic Research

Deep-learning experiments for left-ventricular segmentation and cardiac-function modeling from echocardiogram video.

View research fork ↗Original EchoNet project ↗
Attribution: this work is an independent research extension of the original EchoNet-Dynamic project. The underlying dataset and foundational EchoNet methodology were developed by the original authors.

The research direction

I use the EchoNet-Dynamic framework to investigate how architecture and task design affect cardiac-function prediction, with experiments spanning segmentation, ejection-fraction modeling, multi-task learning, and video-based prediction.

Echocardiogram video → learned visual representation → LV anatomy + cardiac-function prediction

Multi-task learning

One experimental direction uses shared features to jointly learn left-ventricular segmentation and cardiac-function prediction. This tests whether anatomical supervision can improve or regularize representations used for EF-related tasks.

Controlled comparison

A major focus is making comparisons interpretable by holding dataset splits, sampling, preprocessing, optimization, checkpoint selection, and evaluation procedures as constant as possible across model variants.

Evaluation

EF regression

MAE, RMSE, R², and Pearson correlation.

Segmentation

Dice, IoU, precision, recall, specificity, and related pixel-level metrics.

What this project demonstrates
