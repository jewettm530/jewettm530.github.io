Portfolio Research Assistant

A transparent, read-only portfolio analysis system built around explainable scoring, market-data diagnostics, reporting, and reproducible recommendation logic.

View repository ↗

The design problem

Financial dashboards often surface large amounts of data without making the reasoning behind a recommendation inspectable.

This project instead treats recommendations as structured decision support: each signal should be traceable to the data and rules that produced it.

Portfolio + market data → diagnostics & scoring → explainable signals → Streamlit dashboard + reports

Core features

  • Portfolio allocation and health analysis
  • Quote coverage and account-reconciliation diagnostics
  • Hold / watch / trim / sell-review signals
  • Watchlist and portfolio-fit analysis
  • Investment-profile and thesis tracking
  • Recommendation history and audit trail
  • Daily and weekly report entry points
  • CSV / Excel import workflow with review before replacement

Why “explainable” matters here

The current analyst layer is deterministic and rule-based rather than an LLM. Natural-language-style questions are routed to the same scoring engines used throughout the application, keeping the underlying logic testable and reproducible.

Scope: this is an educational research tool. It does not execute trades and its heuristic recommendations are not financial advice or guarantees.

Engineering practices

Modular architecture

Separate modules for market data, portfolio scoring, reconciliation, recommendations, reports, and UI.

Testing

Automated tests, static checks, formatting checks, and GitHub Actions integration.

Privacy

Local account data and configuration are separated from the public repository.

Auditability

Recommendation history and explicit component scores make decisions easier to inspect.
