Mental Health Symptom Severity

Can behavioral measures and resting-state fMRI predict continuous depression, anxiety, stress, and anhedonia severity?

The question

This project uses the Transdiagnostic Connectome Project to compare behavioral, resting-state fMRI, and multimodal predictors of symptom severity. The goal is not only to maximize accuracy, but to test whether imaging adds out-of-sample value beyond behavioral data.

Behavioral features + resting-state fMRI → leakage-safe preprocessing → Random Forest → symptom severity

Approach

  • Four continuous targets: depression, state anxiety, perceived stress, and anhedonia.
  • Behavioral-only, imaging-only, and multimodal feature configurations.
  • High-dimensional imaging reduction performed inside training/CV folds.
  • Repeated cross-validation on training data and held-out test evaluation after model selection.
  • MAE, RMSE, and R² used to compare generalization.

What I found

Behavioral features were the strongest predictors in the current experiments. Anxiety showed the best held-out performance, followed by depression and perceived stress. Anhedonia was substantially more difficult to predict.

Important interpretation: imaging-only models performing poorly does not establish that resting-state fMRI contains no symptom-related information. It means the current sample, representation, and modeling approach did not extract additional predictive value beyond behavioral measures.

What this project demonstrates

  • End-to-end machine-learning experiment design
  • Neuroimaging feature engineering
  • Leakage-aware cross-validation
  • Multimodal model comparison
  • Reproducible results and validation audits
